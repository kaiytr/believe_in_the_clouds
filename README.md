# believe_in_the_clouds
겁 없는 10대 창업가의 뒤를 잇기 위해 자전거를 타고 무려 26km를 달려온 대한민국 자전거계의 전설 엄복동

## 1.1 개발 준비

`codex/first-altar-story-v1.1`은 1.0 완료 기준인 `main`의 `781af6d`에서 시작했다. 첫 재단 스토리의 [상세기획](Docs/FirstAltarStory_Design.md)과 [개발명세서](Docs/FirstAltarStory_TechnicalSpec.md)를 현재 소스에 맞게 갱신했다. 기능 구현은 아직 시작하지 않았다.

신규 프로필은 튜토리얼 다음 첫 일반 전투 출구에서, 1.0 기존 프로필은 업데이트 후 다음 일반 전투 출구에서 프로필당 한 번 진입한다.
