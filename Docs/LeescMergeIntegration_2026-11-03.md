## 자동 검증

Unity 6000.3.5f2에서 원본 프로젝트와 같은 Assets 내용을 가진 독립 복사본을 사용했다. 패키지는 원본과 같은 버전의 기존 캐시를 읽었고, 원본에서 열려 있던 Unity 편집기는 종료하지 않았다. 최종 Assets 전체 해시가 검증 복사본과 일치함을 확인했다.

| 실행 | 전체 | 통과 | 실패 | 스킵 |
| --- | ---: | ---: | ---: | ---: |
| 전체 EditMode | 165 | 165 | 0 | 0 |
| 전체 PlayMode, 그래픽 켬 | 104 | 103 | 1 | 0 |
| 보완 후 재화·로비·스테이지 재검증 | 29 | 29 | 0 | 0 |

전체 PlayMode의 유일한 실패는 새 공중 공격 테스트가 비활성 적을 제외하고 검색하여 3개 중 1개만 찾던 준비 문제였다. 적 활성화·타깃 초기화를 보완한 뒤 관련 29개 테스트가 모두 통과했다. 케이스별 최신 결과를 적용하면 **PlayMode 104개 모두 통과, 미해결 실패 0개**다. 보완 후 전체 PlayMode를 한 번에 재실행한 결과와는 구분한다.

기존 신앙·보스·상자 검증과 코인 낙하·정산, 실제 런 라우팅도 전체 실행에 포함된다. 상점 가격 표시는 1600×900, 확장된 재단 목록은 1600×900 및 1200×900 캡처로 확인했다. 사람이 키보드로 전투를 완주하는 조작감 검증은 수행하지 않았다.

빌드 씬은 기존 Gameplay 7개와 Lobby 시작점을 유지한다. 중복 에셋 GUID와 신규 씬·프리팹 참조 문제는 없었다. 정적 검사에서 별도로 기록한 Renderer2D 셰이더 참조 6개는 병합 전 Puri에도 동일하게 존재한다.
