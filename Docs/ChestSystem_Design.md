# 상자 시스템 상세기획

- 작성일: **2026-11-01 (Asia/Seoul)**
- 상태: **2026-11-01 사용자 확정 후 테스트 씬 범위 구현 완료.** 1.5초 유지·교리 조각 1개 보장·중단 시 진행률 초기화는 확정 규칙이다. [구현 결과](ChestSystem_ImplementationStatus.md), [테스트 가이드](ChestSystem_TestGuide.md)
- 연계 문서: [개발명세서](ChestSystem_TechnicalSpec.md), [재화 상세기획](CurrencySystem_Design.md), [로비 상세기획](LobbySystem_Design.md)
- 아래의 **요청 사항**은 사용자가 제시한 범위이고, **설계 제안**은 미정 부분을 구체화한 검토안이다. 제안값을 사용자 확정 사항으로 취급하지 않는다.

## 1. 목적과 플레이 흐름

플레이어가 스테이지의 상자에 접근해 **E키를 일정 시간 유지하면 개방**하고 보상을 얻는다. 개방 진행률은 **E키를 둘러싼 사각형 외곽선이 한 바퀴 그려지는 모습**으로 전달한다.

**접근 → E 안내 표시 → E 유지 → 사각 테두리 완성 → 개방 확정 → 교리 조각 획득 안내 + 코인 드롭·HUD 이동 → 열린 상자 유지**

아트가 없는 현재 단계에서는 일반 사각형 스프라이트를 상자 외형으로 사용한다. 외형만으로 닫힘·열림을 구분할 수 있게 하고, 나중에 아트와 애니메이션을 교체해도 보상·상호작용 규칙은 유지한다.

## 2. 요청 사항과 설계 제안

### 2.1 사용자 요청 사항

| 항목 | 내용 |
| --- | --- |
| 현재 작업 | 기획 문서 작성 후 개발 시작 지시를 받음. 우선 격리된 테스트 씬에서 검증 |
| 임시 외형 | 일반 사각형 스프라이트 오브젝트 |
| 상호작용 | 가까이 다가가 E키 사용 |
| 개방 입력 | E키를 일정 시간 꾹 누르기 |
| 진행 UI | E키 UI 사각형의 외곽선이 360도 그려짐 |
| 교리 조각 등급 확률 | 일반 65% / 고급 25% / 희귀 10% |
| 기본 코인 | 교리 조각과 별개로 7~17코인 |
| 코인 연출 | 몬스터 드롭처럼 시각적 드롭 효과 후 재화 UI로 이동 |
| 확정 개방 시간 | **E키 1.5초 유지** |
| 확정 조각 수량 | **상자당 교리 조각 1개 보장** |
| 확정 중단 처리 | **진행률 0으로 초기화** |

### 2.2 확정 규칙과 나머지 구현 초기값

| 항목 | 설계 제안 | 이유 |
| --- | --- | --- |
| 개방 시간 | **1.5초** | 사용자 확정 |
| 접근 거리 | **콜라이더 표면에서 2.5 유닛 이내** | 기존 공통 상호작용 거리 규칙과 일치 |
| 조각 지급 개수 | **상자당 1개 보장** | 사용자 확정 |
| 코인 지급 | **개방마다 별도 지급**, 7~17 양 끝 포함 균등 정수 추첨 | 조각 당첨과 독립된 기본 보상 |
| 같은 등급 안의 종류 | 해당 등급의 모든 조각 중 동일 확률로 1개 | 주어·조건·결과의 별도 가중치 없이 시작 |
| 개방 횟수 | 동일 스테이지 인스턴스의 동일 상자당 1회 | 반복 보상 방지 |
| 중단 처리 | 키 해제·범위 이탈·피격·공격/점프/대시·모달·일시 정지 등에 진행률 0으로 초기화 | 초기화는 사용자 확정. 구체적인 취소 조건은 본문 초기안 적용 |
| 이동 | 개방 중 좌우 이동은 허용, 범위 이탈 시 취소 | 별도의 이동 잠금 없이 기존 조작 유지 |
| 조각 획득 | 개방 확정 시 보유 목록에 즉시 추가, 상자 위에 획득 안내 | 수동 줍기 단계 없이 보상을 명확히 전달 |
| 열린 상자 | 어두운 사각형과 열림 표시로 남기고 상호작용 제외 | 이미 사용한 상자를 쉽게 식별 |
| 첫 구현 검증 범위 | 격리된 `ChestTest` 씬에서 검증 후 실제 배치 연동 | 실제 스테이지 보상 배치를 이번 문서에서 임의로 고정하지 않음 |

이 문서는 위 제안을 기준으로 일관된 동작을 정의한다. 값이나 정책을 바꾸면 연결된 개발명세서·검증 기준도 함께 갱신한다.

## 3. 상자 외형과 월드 배치

### 3.1 임시 외형

| 상태 | 외형 제안 |
| --- | --- |
| 닫힘 | 가로 1.2 × 세로 0.9 유닛의 황갈색 사각형 |
| 현재 선택됨 | 외곽을 밝게 강조. 다른 상자에는 강조 없음 |
| 여는 중 | 선택 강조 유지. 진행률은 E UI에서 표시 |
| 처리 중 | 닫힘 외형 유지, 입력 안내를 잠시 `여는 중…`으로 변경 |
| 열림 | 어두운 갈색 사각형 + `열림` 표식. 접근해도 E 안내 없음 |

크기·색상은 테스트용 초기값이다. 조각 등급은 개방 전 외형이나 안내로 노출하지 않는다. 일반/고급/희귀는 **드롭 조각의 등급**이며 별도의 상자 등급 3종을 만드는 요구가 아니다.

### 3.2 충돌과 배치

- 상호작용용 `BoxCollider2D`는 trigger로 두어 플레이어가 통과할 수 있게 한다.
- 거리는 기존 방식대로 **플레이어 위치에서 상자 콜라이더 표면까지** 잰다. 콜라이더 내부는 거리 0이다.
- 캐릭터가 상자보다 앞에 보이도록 스프라이트 정렬을 설정한다.
- 상자 겹침만으로 열리지 않는다. E 입력이 필요하다.
- 시야 가림 판정은 첫 범위에 포함하지 않는다. 벽 너머에서 닿지 않도록 배치 간격으로 관리한다.
- 실제 스테이지별 상자 수·위치·생성 확률·전투 보상과의 관계는 후속 기획이다. 상자를 전부 열어야 클리어되는 조건을 자동으로 추가하지 않는다.

## 4. 상호작용과 취소 규칙

### 4.1 대상 선택과 시작

1. 범위 안의 사용 가능한 공통 상호작용 대상 중 가장 가까운 하나를 선택한다. 상점·재단·출구·상자와 같은 후보 체계를 사용한다.
2. 상자가 선택되면 `[E] 길게 눌러 상자 열기`를 표시한다.
3. **범위 안에서 새로 E키를 누른 순간**부터 유지 시간을 계산한다.
4. E를 미리 누른 채 접근하거나, 모달을 닫으며 E를 계속 유지한 경우에는 시작하지 않는다. 키를 놓고 다시 눌러야 한다.
5. 이미 공격·점프·대시 중이거나 사망·복원·씬 전환·입력 잠금 중이면 시작하지 않는다.
6. 유지 중에는 최초 상자를 대상으로 고정한다. 다른 대상이 더 가까워져도 진행률을 옮기지 않는다.

일반 상점·재단·출구 등 기존 대상은 기존대로 E를 한 번 눌러 실행한다. 상자 때문에 모든 E 상호작용을 길게 누르기로 바꾸지 않는다.

### 4.2 유지와 완료

- 유효한 상태에서 E가 유지된 시간만 누적한다. 기본 1.5초에서 진행률 100%가 된다.
- 범위 안에서 좌우 이동해도 계속 진행한다. 점프는 공중 상태를 포함해 개방 시작·유지를 차단한다.
- 완료 시 접근 거리·생존·상자 상태·입력 잠금 여부를 다시 검사한다.
- 개방 및 보상 저장이 성공해야 열린 상태로 바꾸고 획득 연출을 시작한다.
- 완료 뒤 계속 E를 누르고 있어도 주변의 다음 상자나 다른 시설을 실행하지 않는다. 키를 해제하고 다시 눌러야 한다.
- 같은 판정 시점에 취소 조건과 시간 충족이 함께 관측되면 취소를 우선한다. 이미 저장된 개방 뒤에 발생한 피격·사망은 일반 획득 자산 규칙으로 처리한다.

### 4.3 중단 조건

| 상황 | 처리 |
| --- | --- |
| 완료 전 E 해제 | 진행률 즉시 0, 범위 안이면 대기 안내로 복귀 |
| 범위 이탈 | 취소·진행률 0·안내 숨김 |
| 실제 HP 피해 수락 | 취소·진행률 0. 피해가 무적으로 거부되면 유지 |
| 공격·점프·대시 시작/유효 상태 | 취소하고 기존 전투·이동 동작을 우선 |
| F 입력 | 상자는 보조 기능 없음. 유지 중 F로 다른 대상을 실행하지 않음 |
| 모달 열림 / ESC / 게임 일시 정지 | 취소·진행률 0. 재개 후 새 E 입력 필요 |
| 창 포커스 상실 | 취소·진행률 0. 복귀 시 자동 재시작 금지 |
| 플레이어 사망·교체·비활성화 | 취소. 새 보상 접수 없음 |
| 씬 전환·대상 비활성화·삭제 | 취소. 다음 씬이나 새 대상에 입력·진행률 전달 없음 |
| 저장 실패·거래 중 충돌 | 보상·열림 상태 유지 전으로 복귀, 오류 안내 후 새 입력으로 재시도 |

취소는 코인을 소비하지 않고 상자도 소모하지 않는다. 부분 진행률은 저장하거나 재사용하지 않는다. 취소 후 E를 계속 누르고 있어도 재시작하지 않는다.

## 5. E키 사각 외곽선 UI

### 5.1 표시 위치와 구성

사용자 수정 요청에 따라 **선택한 상자 위에 E 안내를 붙여 표시**한다. 카메라나 상자가 이동하면 UI도 해당 상자를 따라간다. 화면 공간 UI로 그리므로 E와 진행선의 크기는 일정하며, 기준점이 화면 밖이거나 대상이 사라지면 숨긴다. 상점·재단·로비 분기·스테이지 출구도 각 오브젝트 위에 안내를 부착하며, 그 밖에 앵커가 없는 대상은 기존 하단 위치를 사용한다.

구성은 `사각 키캡 안 E`와 오른쪽 `길게 눌러 상자 열기` 문구다. 키캡의 희미한 기본 테두리는 항상 보이고, 별도의 밝은 진행선이 그 위를 따라 그려진다. 내부를 채우는 게이지는 사용하지 않는다.

| 요소 | 초기값 제안 |
| --- | --- |
| 기준 해상도 | 기존 UI와 같은 1920 × 1080 스케일 기준 |
| E 키캡 | 44 × 44 UI 유닛, 중앙 E 글자 |
| 기본 테두리 | 2 UI 유닛, 낮은 명도 |
| 진행 테두리 | 3 UI 유닛, 밝은 미색 |
| 진행 방향 | 위쪽 중앙에서 시작해 시계 방향 |
| 완료 피드백 | 완성된 테두리를 약 0.1초 강조 후 숨김 |

### 5.2 360도 진행의 정확한 의미

**사각형의 둘레를 일정한 속도로 한 바퀴 그린다.** 원형 링이나 원형 부채꼴 게이지로 표현하지 않는다. E 글자는 진행 중에도 고정되고, 선만 증가한다.

| 진행률 | 밝은 선의 끝 위치 |
| ---: | --- |
| 0% | 위쪽 중앙, 진행선 길이 0 |
| 12.5% | 오른쪽 위 모서리 |
| 25% | 오른쪽 변 중앙 |
| 37.5% | 오른쪽 아래 모서리 |
| 50% | 아래쪽 중앙 |
| 62.5% | 왼쪽 아래 모서리 |
| 75% | 왼쪽 변 중앙 |
| 87.5% | 왼쪽 위 모서리 |
| 100% | 위쪽 중앙으로 돌아와 외곽선 전체 완성 |

취소하면 진행선을 즉시 비우며 역방향 애니메이션으로 남은 진행이 있는 것처럼 보이지 않게 한다. 100% 연출은 보상 처리 결과와 구별한다. 저장 실패라면 성공 강조·상자 열림·획득 안내를 재생하지 않는다.

## 6. 보상 규칙

### 6.1 상자 1개 보상 구성

**교리 조각 1개 + 코인 7~17개**를 기본안으로 한다. 코인을 조각 대신 주거나 조각이 나왔다는 이유로 코인 추첨을 생략하지 않는다. 상한 처리 예외는 7절을 따른다.

| 보상 | 추첨 규칙 | 지급 시점 제안 |
| --- | --- | --- |
| 교리 조각 | 일반 65% / 고급 25% / 희귀 10%, 해당 등급에서 종류 1개 | 개방 저장 성공 시 보유 조각에 즉시 반영 |
| 코인 | 7~17 포함, 11개 정수 값 각각 1/11 | 개방 저장으로 지급 권리 확보, 비행 토큰이 HUD에 도착할 때 잔액 반영 |

등급·조각 종류·코인 수량은 서로 정해진 단계로 추첨하며 코인 분포는 조각 등급과 독립이다. 천장·연속 개방 보정·중복 방지·보유하지 않은 조각 우선 규칙은 첫 범위에 추가하지 않는다. 이미 가진 조각도 같은 확률로 나온다.

### 6.2 기존 교리 조각 목록을 사용하는 풀

새 조각 자산이나 별도의 상자 전용 등급을 만들지 않고, 현재 `ShopCatalog`의 ID·등급을 사용한다.

| 등급 | 확률 | 현재 포함 조각 | 개별 조각의 최종 확률 |
| --- | ---: | --- | ---: |
| 일반 | 65% | 플레이어는 / 일반 적은 / 사망하면 / 체력이 30% 이하가 되면 / 이동 속도가 증가한다 | 각 13% |
| 고급 | 25% | 보스는 / 피격하면 / 공격하면 / 공격력이 증가한다 / 회복한다 | 각 5% |
| 희귀 | 10% | 모든 존재는 / 폭발한다 | 각 5% |

위 개별 확률은 현재 5/5/2종과 등급 내 균등 추첨을 적용한 값이다. 주어·조건·결과를 먼저 각각 1/3로 뽑지 않는다. 조각 목록이 늘면 등급별 확률을 유지하고 해당 등급 내부 확률만 다시 나눈다.

밸런스 참고값은 상자당 평균 **12코인**, 평균 조각 수 **1개**다. 현재 상점 가격으로 환산한 조각의 평균 구매 가치는 42.75코인이다. 이는 판매·환급 기능이나 실제 스테이지 상자 수를 정하는 규칙이 아니다.

### 6.3 조각 획득 안내

- 개방 성공 시 상자 위에 작은 사각형 조각 표현과 `일반 · 플레이어는 ×1`처럼 등급·이름·수량을 표시한다.
- 일반은 미색, 고급은 녹색, 희귀는 청색을 초기안으로 쓰되 등급 글자를 함께 표시한다.
- 약 0.8초 동안 조금 떠오른 뒤 사라지는 표현을 제안한다.
- 안내는 표시용이며 조각 지급은 이미 저장된 상태다. 안내가 중단되어도 조각을 다시 지급하거나 회수하지 않는다.
- 조각의 수동 줍기, 코인 HUD로의 비행, 자동 장착, 교리 자동 조합은 포함하지 않는다.

### 6.4 코인 드롭 연출

기존 몬스터 코인 연출과 같은 경로를 사용한다.

1. 상자 중심 또는 상단의 드롭 기준점에서 코인 토큰이 짧게 퍼진다.
2. 토큰이 시간차를 두고 곡선을 따라 **우측 하단 코인 HUD의 실제 위치**로 이동한다.
3. 각 토큰 도착 시 그 토큰이 대표하는 금액을 잔액에 반영한다.
4. HUD가 증가한 수량을 표시한다. 코인에 접근하거나 E를 다시 누를 필요는 없다.

기존 초기값인 퍼짐 0.2초, 비행 0.45~0.7초, 토큰 시차 0.03초를 사용한다. 현재 구현은 보상 1건을 최대 8개 토큰에 묶어 표현하므로 17코인이 꼭 17개 토큰으로 보일 필요는 없다. **토큰 금액의 합이 실제 지급 코인과 같아야 한다.** 상자 전용 비행 로직이나 별도 코인 원장을 만들지 않는다.

## 7. 실패·보유 상한·저장·사망

| 상황 | 설계 제안 |
| --- | --- |
| 보상 저장 실패 | 상자는 닫힌 상태, 조각·코인 모두 지급하지 않음. `보상을 저장하지 못했습니다. 다시 시도하세요.` 표시 |
| 같은 개방 요청 중복 | 최초 결과만 인정. 추가 조각·코인·연출 없음 |
| 추첨한 조각이 9,999개 한도 | 개방 전체를 중단하고 `해당 교리 조각의 보유 한도에 도달했습니다.` 표시. 코인만 지급하거나 다른 조각으로 재추첨하지 않음 |
| 코인 상한 접근 | 기존 규칙대로 보유+대기가 999,999,999를 넘지 않는 금액만 접수. 조각은 정상 지급하고 상자는 열림 |
| 코인 상한으로 전액 미지급 | 조각은 지급, 상자는 열림, 코인 비행 생략. `코인 보유 한도` 안내 |
| 카메라·코인 HUD 없음 | 기존 재화 시스템이 대기 코인을 즉시 정산. 조각 획득도 유지 |
| 비행 중 씬 이동·종료 | 기존 대기 보상 정산·저장 사용. 상자 개방과 조각 획득은 유지 |
| 개방 전 사망 | 유지 동작 취소. 보상 없음 |
| 개방 후 사망 | 이미 얻은 조각과 비행 중 코인도 기존 사망 손실 계산에 포함. 상자 보상을 되돌리거나 재지급하지 않음 |
| 같은 스테이지 재접속 | 열린 상자는 열린 상태. 닫힌 상자의 보상 계획도 동일. 유지 시간만 0부터 시작 |
| 새 런·새 스테이지 인스턴스 | 별도의 상자로 취급. 새 배치가 있다면 각각 1회 개방 가능 |

상자 열림, 조각 추가, 코인 지급 권리 확보는 **하나의 저장 변경**으로 성공하거나 함께 실패해야 한다. 조각 지급만 성공하고 코인만 실패하는 상태를 허용하지 않는다.

## 8. 포함 범위와 후속 범위

### 8.1 다음 개발 단계에 제안하는 포함 범위

- 사각형 임시 상자와 닫힘·선택·열림 표시.
- 공통 상호작용 체계의 선택적 E 유지 동작 확장.
- 사각형 외곽선 진행 UI와 취소·재입력 처리.
- 조각 65/25/10 추첨, 코인 7~17 추첨 및 기존 자산 원장 연동.
- 조각 획득 안내와 기존 코인 비행 연출 재사용.
- 안정적인 상자 ID, 보상 계획·개방 결과 저장, 중복 방지와 기존 저장 이전.
- 격리된 테스트 씬, 자동 검증 및 수동 플레이 검증 항목.

### 8.2 후속 범위

- 정식 아트·음향·상자 열림 애니메이션.
- 상자 등급·열쇠·개방 비용·함정·미믹·선택 보상·연속 개방 보정.
- 스테이지별 상자 생성량·배치·경제 밸런스·클리어 조건 연계.
- 교리 조각의 월드 수동 줍기 및 별도 수집 연출.

## 9. 기획 검토 항목

사용자는 1.5초 유지·교리 조각 1개 보장·중단 시 초기화를 확정하고 테스트 씬 개발을 지시했다. 나머지 항목은 본문의 초기안으로 구현하며, 실제 스테이지 배치는 후속 범위다.

| 중단 조건 | 놓기·이탈·실제 피격·공격/점프/대시 등에 전부 초기화 |
