# 상자 시스템 테스트 가이드

작성일: **2026-11-01 (Asia/Seoul)**

## 실행

1. Unity에서 `Assets/Scenes/ChestTest.unity`를 연다.
2. Play를 누른다. 상자 4개, 우측 안내 기둥, 기존 플레이어와 HUD가 표시된다.
3. A/D 또는 방향키로 상자에 접근한다.
4. **상자 위에 붙은 E 안내**를 보고 **E를 1.5초 유지**한다. 사각 키캡의 위 중앙부터 시계 방향으로 테두리가 완성되면 열린다. 안내는 상자와 카메라의 이동을 따라간다.

상자당 **교리 조각 1개 + 7~17코인**이다. 조각은 일반 65%·고급 25%·희귀 10%이며, 같은 등급 안에서 균등하게 선택한다. 조각은 즉시 보유 목록에 반영되고 코인은 상자에서 퍼진 뒤 우측 하단 HUD로 날아간다. 열린 상자는 어두워지고 `열림`으로 표시된다.

상자별 보상은 테스트 스테이지 등록 시 정해진다. 열지 않은 상자를 취소하거나 저장을 다시 읽어도 보상을 바꾸지 않는다. 새 테스트 프로필은 새 스테이지 ID를 사용하므로 새 보상 계획이 생성된다.

## 테스트 저장과 초기 상태

- **실제 사용자 저장 파일을 사용하지 않는 메모리 프로필**이다. 시작은 0코인·0조각이며 자동 장착도 없다.
- `저장 재로드` 버튼은 같은 메모리 저장을 새 서비스로 불러오는 재접속 상황을 재현한다. 열림 상태·조각·코인 결과가 유지된다.
- 비행 중 재로드하면 기존 재화 규칙에 따라 대기 코인을 한 번 정산한다.
- **Play를 종료하고 다시 시작하면 테스트 프로필은 초기화된다.** 이 씬에서 디스크 이어하기를 제공하는 것은 아니다. 실제 JSON 저장 형식과 구버전 이전은 자동 검증 대상이다.
- 테스트 씬을 떠나면 진입 전 재화 서비스 바인딩을 복원한다.

## 좌측 테스트 도구

| 도구 | 확인할 동작 |
| --- | --- |
| 피해 10 | 피격이 수락되면 진행 취소. 무적 시간 중 거부된 피해는 취소하지 않음 |
| 저장 실패 ON/OFF | ON에서 개방을 완료해도 상자·조각·코인이 함께 유지됨. OFF 뒤 E를 놓고 새로 시도 |
| 저장 재로드 | 같은 저장을 재로드. 열린 상자가 닫히거나 보상이 다시 지급되지 않음 |
| 새 빈 테스트 프로필 | 모든 상자와 자산을 초기화한 새 메모리 프로필 생성 |
| 모달 열기 | 홀드 취소 및 월드 입력 차단. E/ESC/닫기 버튼으로 닫음 |
| 체력 회복 | 테스트 플레이어의 체력 회복 |

마우스 클릭은 기존 공격 입력과도 연결되므로 버튼 클릭 시 홀드가 중단될 수 있다. 피격과 무적 거부 피해의 정확한 구분은 실제 피해 API를 호출하는 PlayMode 자동 검증으로도 확인한다.

반복 피해로 사망했다면 `새 빈 테스트 프로필`을 눌러 다시 시작한다. `체력 회복`은 살아 있는 플레이어의 회복이다.

## 직접 확인할 항목

| 조작 | 기대 결과 |
| --- | --- |
| E를 짧게 누른 뒤 해제 | 열리지 않음, 진행률 즉시 0 |
| 1초 유지→해제→다시 누름 | 다시 1.5초를 유지해야 열림 |
| E를 미리 누른 채 상자 접근 | 시작하지 않음. 놓고 다시 눌러야 함 |
| 유지하며 범위 밖 이동 | 즉시 취소. 범위 안으로 복귀해도 자동 재시작 없음 |
| 범위 안 좌우 이동 | 진행 유지. 점프·대시·공격은 진행 취소 |
| 상자 사이에서 유지 | 시작한 상자 하나에 진행 고정. 다른 상자로 진행 이전 없음 |
| 완료 뒤 E 계속 유지 | 다음 상자는 자동으로 열리지 않음 |
| 열린 상자 재접근 | 해당 상자의 E 안내·추가 보상 없음 |
| 코인 비행 관찰 | 상자에서 퍼짐→HUD 이동→잔액 증가. 토큰 개수와 실제 금액은 다를 수 있음 |
| 모달을 E로 닫고 계속 유지 | 상자 개방이 시작되지 않음. 새 E 입력 필요 |
| ESC·다른 창으로 포커스 이동 | 진행 취소, 복귀 시 재입력 필요 |
| 우측 청록색 안내 기둥에 E | E 한 번으로 안내 열림. 기존 즉시 상호작용과 공존 |
| 16:9 / 16:10 / 4:3 화면비 | E 글자·사각 진행선·안내·재화 HUD 가독성 확인 |

전투 전체의 저장·실제 스테이지별 상자 배치·정식 아트 및 음향은 이번 테스트 씬 범위 이후 작업이다.

## 에셋 재생성

씬 또는 프리팹을 다시 생성하려면 `Tools > Chest > Build independent test scene`을 사용한다. 이 메뉴는 **ChestTest 씬과 Chest 프리팹을 다시 저장하므로 수동 편집을 대체한다.** 일반적인 실행에는 재생성이 필요하지 않다.

자동 검증은 `ChestEditModeTests`와 `ChestPlayModeTests`에 있다. 실행 결과와 남은 확인 항목은 [구현 결과서](ChestSystem_ImplementationStatus.md), 규칙은 [상세기획](ChestSystem_Design.md), 구조는 [개발명세서](ChestSystem_TechnicalSpec.md)를 참고한다.
