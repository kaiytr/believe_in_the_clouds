# 적 공통 피격 이동 경직

일반 적(개·신자·간부)과 보스는 `EnemyHitReaction`을 함께 사용한다. 지상 공격은 수평 넉백과 이동 경직, 공중 내려찍기는 넉백 없는 이동 경직을 적용한다. HP 피해가 실제로 받아들여진 대상에게만 전달하며 사망한 적은 받지 않는다.

## 조정 값

공통 Player 프리팹의 `PlayerAttack`에서 조정한다.

| 항목 | 기본값 |
| --- | --- |
| `groundHitStunSeconds` | 0.18초 |
| `airHitStunSeconds` | 0.2초 |
| 지상 1·2·3타 넉백 속도 | 콤보의 `knockback` 2·3·4에 1.4를 곱한 2.8·4.2·5.6 |

지상 경직 시간이 끝나도 넉백이 남아 있으면 자체 이동을 막는다. 넉백은 기존 50 Hz 감쇠 곡선을 유지하고 최대 속도 16으로 제한한다. 연속 피격은 기존 종료 시각과 새 피격 종료 시각 중 늦은 시각으로 갱신하며 대기 시간을 합산하지 않는다. 공중 내려찍기는 이전 타격의 남은 수평 넉백도 비우고 자체 이동을 정지한다. 중력과 기존 수직 속도는 유지한다.

## 이동 연결

- `EnemyUnit.FixedUpdate`는 공통 반응을 먼저 적용하고, 경직 중에는 AI 이동 속도를 쓰지 않는다. 공격용 이동 잠금과 피격 경직은 별도로 판단하므로 공격 종료의 `UnlockMovement`가 경직을 해제하지 않는다.
- 개 돌진은 경직 중 자체 속도와 돌진 진행 시간을 갱신하지 않는다. 뒤로 밀린 거리를 전진 거리로 세지 않고 종료 후 남은 돌진을 재개한다.
- 보스 전진·대시는 물리 틱당 이동 요청을 공통 반응에 전달한다. 피격이 들어오면 예약된 자체 이동을 비우고, 보스 물리 갱신이 넉백 또는 이동 정지를 우선 적용한다. 보스의 대시도 경직 종료 후 남은 이동을 재개한다.
- 이동 경직 자체는 공격 코루틴·이미 발사된 투사체를 취소하지 않는다. 기존 사망·믿음 변화·페이즈 전환에 따른 취소 규칙은 각 전투 컨트롤러가 처리한다.
- 사망·비활성화·보스 전투 초기화 시 피격 상태와 예약 이동을 비운다. 기존 씬·프리팹은 필수 컴포넌트 선언 및 런타임 연결로 적용된다.

## 검증 항목

실제 플레이어 지상·공중 판정으로 피격 반응을 확인하고, 추격 복원·연속 경직 갱신·공격 잠금 해제와의 독립성·사망/비활성화 정리를 검사한다. 실제 전투 씬의 개 돌진, 보스의 전진·대시 및 공통 Player 설정과 모든 적의 컴포넌트 연결도 확인한다.

Unity 6000.3.5f2의 별도 임시 프로젝트 복사본에서 다음 검사가 통과했다.

- PlayMode 9/9: 공통 반응 4개, 실제 개 돌진 1개, 실제 보스 피격 2개, 보스 콤보·고속 투사체/대시의 얇은 벽 충돌 회귀 2개.
- EditMode 14/14: 플레이 씬 11개의 공통 Player 설정·적 컴포넌트 연결, 공통 전투 검사 3개. 플레이어가 없는 타이틀·엔딩 씬은 Player 설정 검사 대상에서 제외한다.

보스 검사 준비는 현재 아레나 범위와 플레이어 몸 크기·체력을 사용하도록 맞췄다. 콤보 타격 피해 검사는 별도 몸 접촉 피해를 억제해 타격만 확인한다. 전체 테스트 묶음이나 배포 빌드는 실행하지 않았다.
