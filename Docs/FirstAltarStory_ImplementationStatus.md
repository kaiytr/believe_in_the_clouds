# 첫 재단 스토리 — 1.1 구현 결과

작성일: 2026-11-11. 브랜치: `codex/first-altar-story-v1.1`. 1.0 기준 `main`의 `781af6d`는 변경하지 않았다. 배포 빌드는 이번 작업에서 생성하지 않았다.

## 적용한 흐름

신규 프로필은 튜토리얼 완료 후 첫 일반 전투 출구, 1.0 기존 프로필은 업데이트 후 다음 일반 전투 출구에서 전용 씬에 진입한다. 상점·보스·분기 리롤·해금 도구는 이벤트 진입을 소비하지 않는다. 프로필당 한 번이며 사망으로 새 런이 시작되어도 완료 기록을 유지한다.

신도 원고는 처음부터 첫 단독 사과까지 한 번 자동 재생한 뒤 사과만 반복한다. 그동안 자유 이동하며, 사과 반복 준비 후 현재 접근 범위에 있을 때 사망 컷씬을 시작한다. 작은 말풍선 문자 글리치와 신체 일부의 가로 왜곡을 적용했다.

완전 암전 → 빗소리 상승 → 둔탁한 타격음 1회 → 타격음 뒤 실제 3초 암전 → 혈흔·시체가 있는 화면으로 즉시 복귀한다. 사망 저장 실패 시 혈흔 화면과 입력 잠금을 유지하며 저장만 재시도한다. 같은 실행에서 타격음과 암전을 다시 재생하지 않는다.

사망 저장 및 컷씬 종료 후 재단을 활성화한다. 기록 UI는 E로 열고 E/ESC/닫기 버튼으로 닫는다. 열람 저장 실패 시 창을 유지한다. 성공 후 방에 남으며, 키·마우스 해제를 거친 새 E 입력으로 출구에서 로비에 복귀한다. 재열람도 가능하다.

## 저장과 연결

- 저장 스키마 v5, `NarrativeProgressData`, `RunArea.StoryRoom=4`를 추가했다. 기존 enum 숫자와 `BranchRole=2` 제거 마이그레이션은 유지한다.
- 유효한 v1~v4 파일은 자산·런·사망 저널·TIP·영수증을 유지하고 LegacyEligible 자격을 추가한다. v5 필수 내러티브 영역이 빠진 파일은 새 이벤트로 초기화하지 않고 거부한다.
- 원본 Combat stage·상자 상태를 방 안에서 보관한다. 입장 때 클리어 +1, 실제 로비 복귀 때 visit +1·다음 후보 생성이다. 출구 영수증과 후보 seed는 기존 ID 계약을 유지한다.
- 기존 런 스냅샷 캐시를 제거하고 현재 거래 복사본에서 결정적으로 계산해 저장 실패 뒤 진행·HP가 덮어써지지 않도록 했다.
- 명세의 접근 트리거·사망 외부 단계·암전·오디오 책임은 `StoryRoomFlow`에 묶고, 기도·신도 표시·문서 UI·상호작용은 별도 컴포넌트로 분리했다. 연결 지점을 줄이면서 저장 단계와 입력 조건은 같은 계약을 따른다.
- 튜토리얼 연습 서비스가 아닌 정식 서비스에 완료를 저장하고, 정식 서비스를 복원한 뒤 로비를 로드한다. 타이틀은 PlayerPrefs 진입 키 대신 프로필의 tutorial 단계로 판단한다.
- F2 전체 초기화는 기존과 같이 새 프로필을 만든다. 튜토리얼 초기화 메뉴는 다음 Editor Play에서 격리된 메모리 프로필을 사용하고 실제 저장 파일은 유지한다.
- 컷씬·문서 UI·닫기 입력 해제 중에는 F2가 진행을 끊지 않는다. StoryRoom에서 보스 해금·분기 리롤은 비활성이다.

## 실제 수행한 검증

Unity `6000.3.5f2`에서 런타임·에디터·테스트 어셈블리 컴파일과 씬·프리팹·데이터·메타 생성이 완료됐다.

- `FirstAltarStoryEditModeTests`: **8/8 통과**. 실제 Unity JsonUtility/JsonEconomyStore로 v1~v4 호환, v5 필수 단계 누락 거부, 저장 실패·진행 변경 후 재시도, 중복 거래, 클리어/방문 분리, 런 교체 후 재진입·완료 유지 확인.
- `FirstAltarStoryPlayModeTests`: **1/1 통과**. 실제 씬에서 사과 반복, 접근 컷씬, 실제 3초 암전, 저장 실패 중 화면 복귀·재시도, 재단/출구 순서, UI 닫기 저장 실패, 새 출구 E 입력의 로비 복귀 확인. 기도 대기만 테스트용 복사 데이터에서 단축했고 3초 암전은 단축하지 않았다.
- 전용 방의 생존·혈흔 구도를 오프스크린 렌더링해 확인했다. 최종 UI 디자인·청감·긴 원고 전체의 실제 속도는 수동 최종 연출 검수 범위로 남긴다.
- 문서 링크·원고 보존, Git 공백·메타·씬 참조를 확인했다. 전체 EditMode/PlayMode 회귀나 배포 빌드는 실행하지 않았다.

이 결과를 전체 프로젝트 테스트나 최종 1.1 배포 빌드 완료로 해석하지 않는다. 실제 배포 단계에서 `bundleVersion=1.1` 변경과 대상 플랫폼 빌드가 필요하다.
