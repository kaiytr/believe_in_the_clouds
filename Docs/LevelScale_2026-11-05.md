# 플레이어 크기에 맞춘 레벨 확장

기준 커밋: `aa0496c`. 튜토리얼·일반 전투 1~6·로비·상점의 9개 제작 씬에 적용했다.

## 크기와 점프

- 공통 플레이어 충돌체: 폭 1, 높이 2 유닛. 일반 맵의 타일 한 변은 0.74 유닛으로, 플레이어 높이는 약 2.70칸이다.
- 타일의 정사각형 비율과 플레이어·적·상자·문의 크기를 유지했다.
- 기존 발판의 가로 위치·폭과 바닥에서의 높이를 2배로 늘렸다. 발판 자체의 두께는 유지하며, 타일을 추가 배치했다.
- 바닥 타일도 가로와 아래 방향의 칸수를 2배로 채웠다. 로비·상점은 평지 배치를 확장하고 상호작용 지점을 함께 옮겼다.
- 공통 플레이어의 `jumpPower`: **14 → 15.64**. 이동 속도 7, 중력 배율 4, 물리 틱 0.02초 기준이다.
- 중력을 먼저 적용하는 물리 적분으로 계산하면 정점은 약 **2.96096 유닛 = 4.0013칸**이다. 기존 값 14의 정점은 약 3.19칸이었다.

점프 정점은 출발한 발 위치의 상승량이다. 교리·넉백·대시·공격 등 추가 속도가 없는 기본 점프를 기준으로 한다. 일반 맵보다 타일 변이 조금 다른 로비·상점에서도 같은 공통 플레이어 설정을 사용한다.

## 함께 조정한 항목

- 플레이어·적·상자는 각자 기존에 놓여 있던 바닥/발판에서의 높이 차이를 유지해서 이동했다.
- 출구, 튜토리얼 안내, 로비 분기 슬롯, 재단 앵커, 맵 경계, 6번 맵 봉쇄 문을 이동했다.
- 실내 배경은 가로로만 반복 배치한다. 벽돌·기둥 몸통·창문 세로틀을 모듈로 연결하고, 방마다 바닥 몰딩과 천장이 한 번씩 나타나도록 구성했다.
- 제작 맵의 탐색 카메라는 선택적으로 세로를 추적한다. 6번 맵의 전투 고정 카메라는 가로 폭과 세로 범위를 모두 화면에 담는다.
- 저장 위치의 가로·세로 제한을 확장했다. 로비의 위치 제한과 월드 안내문 위치도 씬에서 설정할 수 있게 했다.
- 시작 카메라를 새 플레이어 시작 위치에 맞췄다.

## 확인 범위

Unity Editor/BatchMode와 EditMode/PlayMode 테스트는 실행하지 않았다.

직렬화된 9개 씬을 대상으로 타일 참조 개수, 씬 내부 참조, 타일/충돌체 정렬, 유지 대상의 스케일을 확인했다. 일반 이동 속도와 기본 점프를 사용한 발판 연결 계산에서 7개 제작 맵의 64개 기존·추가 발판에 도달하는 경로가 있다. 연결 계산은 최대 3칸 상승과 여유 있는 수평 간격을 사용하며 대시를 요구하지 않는다.

런타임 C# 컴파일과 `git diff --check`는 통과했다. 실제 Unity 충돌 판정, 점프 착지 감각, 적의 전투 밀도와 화면비별 체감은 직접 플레이로 확인해야 한다. 특히 6번 맵은 전체 전투 공간이 넓어져 봉쇄 중 카메라가 이전보다 멀리 보인다.

## 배경·바닥·발판 외형 보완

실내 화면을 위아래로 복제하던 배치를 제거했다. 공통 `InteriorHallBay` 프리팹은 한 개의 높은 방을 표현하며, 로비·상점은 같은 조각의 높이를 낮춰 사용한다. 창문은 아치·세로 창틀·창턱으로 조립하고, 일부 구간은 창문 대신 벽걸이 천을 배치했다.

지형은 원본 아틀라스의 갈색 석재 계열로 맞췄다. 바닥 아래는 장식 테두리가 반복되지 않도록 벽돌 64×64 영역을 16개의 타일로 나눠 연속 패턴을 구성한다. 넓은 발판의 양 끝은 원본 48×32 석조 받침 조각으로 마무리한다. 원본 PNG 픽셀은 수정하지 않고 스프라이트 영역과 배치를 사용했다.

배경은 어둡고 차가운 색, 지형은 밝고 따뜻한 석재 색으로 구분한다. 창문 안쪽 밝기도 함께 낮춰 걷는 바닥과 발판의 윗면이 먼저 보이도록 했다. 일반 구간의 방 높이는 18.5 → 11.84 유닛, 높은 발판이 있는 1·5·6번 맵은 18.5 → 15.54, 로비·상점은 9.62 → 7.4로 낮췄다. 창문 높이도 일반 구간은 8.88 → 4.44 유닛으로 줄였다.

높이는 각 씬의 바닥에서 천장까지의 거리다. 가장 높은 발판에서도 4칸 점프를 하면 머리 위에 최소 0.2 유닛이 남도록 했으며, 탐색 카메라의 세로 상한도 낮춘 방 높이에 맞췄다.

[에셋 배치 미리보기](LevelSceneryPreview_2026-11-05.png)는 실제 씬의 스프라이트·타일·배치 데이터를 합성한 참고 이미지다. Unity 플레이 캡처가 아니며, 렌더러의 최종 색상·UI·조명 효과와는 차이가 있을 수 있다.

보완 전후 9개 씬의 모든 기존 위치·스케일, Rigidbody·충돌체·단방향 플랫폼 설정, 타일 좌표가 동일함을 확인했다. 새 스프라이트·타일 참조와 장식 재생성의 중복 여부도 확인했다. Unity Editor/BatchMode와 EditMode/PlayMode 테스트는 실행하지 않았다.

## 재현 도구

`Tools/resize_level_layouts.py`는 이번 씬 변경에 사용한 단발성 변환 도구다. 저장소 루트에서 `python3 Tools/resize_level_layouts.py`로 계획을 확인하고 `--apply`로 적용한다. 모든 씬의 원본 칸수를 확인한 뒤 쓰며, 이미 확장한 씬에는 다시 배율을 적용하지 않는다. 플레이어나 런타임 스크립트 설정은 도구가 변경하지 않는다.

`python3 Tools/refine_level_scenery.py`는 공통 실내 프리팹과 9개 씬의 배경·지형 외형을 적용한다. 확장 도구 적용 후 실행하며, 반복 실행해도 장식을 중복 생성하지 않는다.
