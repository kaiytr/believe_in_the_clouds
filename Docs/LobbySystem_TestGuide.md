# 로비·임시 스테이지 테스트 가이드

기준: Unity 6000.3.5f2 / [상세기획](LobbySystem_Design.md). 이번 임시 스테이지는 실제 전투·상점·이벤트 콘텐츠 대신 완료 상태와 왕복을 검증한다.

## 시작

1. `Assets/Scenes/Lobby.unity`를 열고 Play한다.
2. 기존 이동·Space 점프·대시·공격으로 오른쪽 분기 구역까지 이동한다. 사각형은 통과할 수 있다.
3. 가까운 사각형에서 **E 출발**, **F 역할 공개(5코인)**. 두 동작 모두 즉시 실행한다.
4. 임시 스테이지에서 테스트 도구의 **역할 완료**를 누른 뒤 오른쪽 출구에서 **E**로 복귀한다.

처음에는 0코인으로 시작한다. 공개하지 않고 E로 출발할 수 있다. `TemporaryStage.unity`에서 직접 Play해도 저장된 영역으로 이동하므로 시작은 Lobby를 권장한다.

## 테스트 도구

좌측 상단 패널은 **F2**로 표시/숨김을 전환한다.

| 버튼 | 동작 |
| --- | --- |
| 새 메모리 테스트 | 빈 프로필로 새 런 시작. 디스크의 기존 저장은 유지. Play 종료 시 이 프로필은 사라짐 |
| +100 코인 | 현재 테스트에 100코인 지급 |
| 역할 완료 | 현재 임시 스테이지 완료. 전투 클리어 수는 출구로 복귀할 때 증가 |
| 피해 10 | 기존 피해·무적 처리로 10 피해. 연속 입력은 무적 시간의 영향을 받음 |
| 사망 | 무적 중에도 사망 검증. 기존 손실 처리 성공 후 새 런·최대 HP로 로비 복귀 |
| 저장 다시 불러오기 | 현재 저장소에서 재로드. 메모리 테스트도 저장된 런·HP·공개 상태 복원 가능 |
| 저장 실패 켜기/끄기 | **새 메모리 테스트**에서만 사용. 해제 후 사망/체력 체크포인트는 자동 재시도, 공개·출발·완료·복귀는 다시 입력 |

메모리 테스트를 시작하지 않은 상태의 코인 지급·공개·진행은 현재 Editor 프로필에 저장된다. 실제 종료 후 이어하기 검증은 메모리 테스트를 사용하지 않고 진행한다.

## 직접 확인할 항목

| 확인 | 예상 결과 |
| --- | --- |
| 공간·조작 | 긴 로비를 이동하면 카메라가 추적. 기존 점프·대시·공격 가능, 바닥/양쪽 경계 밖으로 낙사하지 않음 |
| 사각형 통과 | 막히지 않고 캐릭터가 앞에 보임. 겹치기만 하면 결제·출발하지 않음 |
| 입력 대상 | 가까운 한 후보가 강조되고 E/F가 같은 후보에 동작. 안내는 각 분기/출구 위에 부착되어 카메라 이동을 따라감. 키를 계속 누르고 있어도 반복 결제·연속 씬 전환 없음 |
| 공개 | 기본 회색·`?`. F 한 번에 대상 하나만 역할명·색상 공개, 정확히 5코인. 재공개 무료 |
| 부족·무료 출발 | 0~4코인에서 공개 실패, 차감 없음. 미공개 E 출발 가능. 정확히 5코인에서 공개 후 0코인 |
| 후보 구성 | 새 묶음마다 총 2~3개·전투 최소 1개, 상점·이벤트 중복 없음. 공개한 후보도 복귀 시 새 후보로 교체 |
| 완료 전 출구 | 출구/ESC로 복귀 불가. 역할 완료 후에만 출구 E 사용 |
| 정상 왕복 | 피해 후 완료·복귀 시 남은 HP 그대로. 전투는 복귀 때 1회 증가, 상점·이벤트는 증가하지 않음 |
| 보스 | 전투 0~2회에는 없음. 3회 이후 일반 후보와 같은 추첨 풀에 추가, 매 묶음 등장 보장은 없음. 공개 비용 동일 |
| 임시 보스 완료 | ‘런 완료 검증’ 표시. 정식 엔딩/일반 출구 귀환 대신 여기서 멈춤. 다음 테스트는 새 메모리 테스트 |
| 사망 | 손실 한 번, 전투 횟수 0·새 미공개 후보·최대 HP로 로비 복귀. 보스 다시 잠김 |
| 로비 이어하기 | 공개 후 Play 종료/재실행 시 같은 후보·위치·공개 상태·잔액·HP. 후보 재추첨 없음 |
| 스테이지 이어하기 | 피해 또는 완료 후 Play 종료/재실행해도 같은 스테이지·HP·완료 여부. 종료만으로 귀환/클리어하지 않음 |
| 저장 실패 | 메모리 테스트에서 실패 켠 뒤 공개/출발/완료/복귀: 부분 적용·씬 이동 없음. 실패 해제 후 재입력 가능 |
| 사망 저장 실패 | 실패 켜고 사망: 죽은 씬에서 대기, 일반 조작 잠금. 실패 해제하면 손실 한 번 적용 후 로비 복귀 |
| 화면비 | 16:9와 4:3에서 사각형·키 안내·HP·잔액·테스트 버튼이 구분 가능 |

보스 추첨은 확률이므로 세 번 전투 후에도 여러 묶음 동안 보스가 없을 수 있다. 출발 전에는 정보 공개 없이는 전투도 구분할 수 없는 것이 정상이다.

## 저장과 재생성

- Editor 프로필: `Library/Economy/Editor/economy-save-v1.json` 및 `.bak`.
- 실행 파일: `Application.persistentDataPath/economy-save-v1.json`.
- 파일명은 기존 재화를 이어받기 위해 유지하고 **내부 schemaVersion은 2**로 확장했다. v1 자산은 초기화하지 않고 마이그레이션한다.
- 실제 프로필을 초기화할 필요 없이 **새 메모리 테스트**로 빈 상태를 검증할 수 있다.
- 씬을 다시 생성할 때만 `Tools > Lobby > Build lobby and temporary stage` 사용. 두 씬의 수동 배치는 생성 결과로 교체된다.

기존 장착 조합의 씬 전환 유지/전체 이어하기, 실제 적·상점 결제·이벤트 보상·재단·정식 보스와 엔딩은 후속 연결 범위다.
