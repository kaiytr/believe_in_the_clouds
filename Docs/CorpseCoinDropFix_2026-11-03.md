# 넉백 후 시체 위치에서 코인 드롭 — 2026-11-03

기존에는 치명타 순간의 위치를 고정한 뒤 코인 연출만 지연했다. 플레이어 공격은 적에게 피해를 준 다음 넉백을 가하므로, 시체가 이동해도 코인은 처음 맞은 위치에서 나왔다. 연출 지연은 실시간이고 시체 제거는 게임 시간이어서 히트스톱/일시정지에서도 시점이 어긋날 수 있었다.

`CoinDropOrigin`이 시체의 몸 중심을 추적하고 `EnemyUnit.OnDestroy`에서 최종 좌표를 확정하도록 변경했다. `CoinFlightRequest`와 경제 런타임 재시도는 이 위치 참조를 공유한다. `CoinFlightView`는 시체 제거까지 대기하고, 모든 코인을 같은 최종 좌표에서 출발시킨다. 시체가 먼저 사라지고 보상 저장이 나중에 성공해도 최종 좌표를 유지한다.

보상 예약/드롭 수량/거래 ID 중복 방지/지면 착지/바닥 대기/HUD 이동/사망 페널티는 기존 정책을 유지한다. 시체 위치 정보는 연출 전용이며 저장 스키마를 변경하지 않는다. 시체와 무관한 지급 API의 선택적 연출 지연도 유지한다.

변경한 런타임 파일은 `EnemyUnit.cs`, `EconomyModels.cs`, `EconomyService.cs`, `EconomyRuntime.cs`, `CoinFlightView.cs`이다. `EconomyPlayModeTests.cs`와 `StageIntegrationPlayModeTests.cs`에 회귀 검증을 추가했다.

Unity 6000.3.5f2 독립 복사본에서 대상 PlayMode **27/27 통과**:

- 실제 적을 처치한 다음 Rigidbody에 넉백을 적용해 시체가 이동하는 상황 재현.
- 시체가 남아 있거나 게임 시간이 정지한 동안 코인이 먼저 나타나지 않음.
- 코인 화면 좌표가 치명타 좌표가 아닌 시체 최종 좌표와 일치함.
- 착지 후 바닥 대기, 카메라 이동 시 월드 위치 유지, 단일 잔액 정산.
- 보상 저장 실패 → 시체 이동/소멸 → 저장 복구에서도 최종 위치 유지 및 추가 드롭 방지.
- 기존 경제·사망 결과·로비·플레이어 사망 시 보스 취소 테스트.

결과 XML, 요약과 실제 StageTest 렌더 이미지는 `CorpseCoinDropVerification/`에 포함한다. 전체 PlayMode 모음과 배포 빌드 수동 플레이는 이번 검증 범위에 포함하지 않았다.
